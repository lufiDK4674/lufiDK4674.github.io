# Smart Vision Quality Control System

## Overview
AI-based conveyor automation system for freshness detection, logo recognition, and text OCR. Integrated YOLOv8 with NodeMCU IR sensors for real-time system control. Won 3rd Place at BIT Sindri Innovathon.

## Category
Computer Vision (Featured project)

## Tech Stack
Python, OpenCV, YOLOv8, TensorFlow, Arduino, NodeMCU
